# DACON Q&A 정리 — 새로 알게 된 것과 대응

작성: 2026-09-27 · 출처: DACON 대회 Q&A (다른 참가자 질문 포함)

## 1. 이미 알던 것 (확인만 됨)

- 평가 Stage 2 = 블랙박스 차량(피의차량)과 피해차량의 **직접 충돌만**. 무충돌 영상 없음
- `entry_side` = LEFT/RIGHT 두 범주만. `evasion_space` = 정수 0/1만
- 평가 영상은 **전부 실촬영**(시뮬레이션 없음)
- Stage 3 가감속 = CAN 차속·종가속도 기반

## 2. 새로 알게 된 것

| # | 사실 | 우리에게 주는 의미 |
|---|---|---|
| 1 | **조향 라벨 = CAN 조향각 신호 기반** | 조향각은 요레이트가 아니라 **곡률(요레이트 ÷ 속력)** 에 비례한다(자전거 모형 δ ≈ L·ψ̇/v). 지금 조향은 광류 수평성분(요레이트 대리값)을 쓴다. 저속 교차로 회전은 조향각이 크지만 요레이트가 작아 놓치고, 고속 차선변경은 반대로 과하게 부른다 |
| 2 | **정답이 STOPPED 인 프레임은 조향 채점에서 제외** | 정지 구간 조향 출력은 점수와 무관하다 |
| 3 | **Macro-F1 은 정의된 전체 범주 기준** (가감속 4, 조향 3 항상) | 드문 범주(예: STOPPED, LEFT)를 한 번도 안 부르면 그 범주 F1 = 0 이 그대로 평균에 들어간다 → 드문 범주를 적극적으로 부르는 쪽이 유리할 수 있다 |
| 4 | **진입 시점 = 피해차량 바퀴가 피의차량 차선에 처음 닿는 시점.** 차선 표시가 없으면 도로 구조로 가상 차로를 판단 | 차체 중심이 아니라 **바퀴가 닿는 순간**이라 충돌보다 꽤 이르다 |
| 5 | **영상 시작 전에 이미 진입했으면 entry_frame = 첫 프레임** | 평가 충돌이 클립 앞쪽에 많다(E32). 진입이 영상 밖인 클립이 많을 수 있다 → **"entry = 첫 프레임" 탐침**이 싸고 유익하다 |
| 6 | **회피 공간 = 충돌 시점에 진행 방향을 바꿔 들어갈 물리적 공간**(차로·경계·분리대·주변 차량 고려, 반대차선 제외). 속도·반응시간은 고려하지 않는다 | 지금 휴리스틱(충돌 전후 변화량 비교)은 이 정의와 무관하다 |
| 7 | **AI Hub 데이터 사용 가능.** 가입·신청·승인 필요, 가중치 제출 가능, 원본 영상은 제출 금지 | 「교통사고 영상 데이터」(21,895건, 블랙박스+CCTV, 국내 실촬영)에 **파손 위치 · 차량 진행 정보 · 사고 유형 · 객체 박스(9종)** 라벨이 있다. **라이선스가 깨끗한 entry_side 학습 데이터**이고 평가와 같은 국내 도메인이다 |
| 8 | 2차 평가: 학습 데이터 원본 제출이 원칙. 재배포가 제한된 제3자 저작물은 **제출하지 말고 보고서에 기재**(데이터셋명·출처·취득 경로·라이선스·활용 범위·제한 사유) | CCD(YouTube 원본)는 보고서 기재 방식이다 |
| 9 | Stage 3 평가: 10Hz, sample_index 개수 = 디코딩 프레임 수 | 현행 구현과 일치 (확인됨) |

## 3. 대응 (실행 비용 0 → 우선)

| 우선 | Stage | 실험 | 근거 |
|---|---|---|---|
| 1 | 3 | **조향 신호를 곡률로:** 수평 요 대리값 ÷ max(학습 속력, v0) | #1. 조향각 = 곡률. 이미 두 신호가 다 있다 |
| 1 | 2 | **entry = 첫 프레임 탐침** (전 클립) | #5. 진입이 영상 밖인 클립 비율을 읽는다. 지금 entry 적중 11% |
| 2 | 3 | 드문 범주 적극 호출 (가감속 민감도 ↑) | #3. 전체 범주 Macro-F1 |
| 3 | 2 | AI Hub 파손 위치로 entry_side 학습 | #7. 신청 승인이 필요하다 (사용자 계정, 내국인) |
