# 1등을 목표로 하는 실행 계획

## 결론

우승 가능성은 “큰 영상 모델 하나”가 아니라, **Stage별 데이터 공백을 메우고, 파일 단위로 엄격히 검증한 앙상블을 60분 안에 재현하는 체계**에서 나온다. 현재 공개 예제만으로는 Stage 2의 진입·회피·방향을 학습할 정답이 없으므로, 오늘의 3개 제출은 순위 공격보다 측정 장비를 만드는 단계다.

## 2026-08-27 개정 — Stage별 1위 점수 확인에 따른 우선순위 재배치

Stage별 현재 1위 점수를 확인했다. 이 숫자는 아래 원안의 핵심 전제 하나를 뒤집는다.

| Stage | 현재 1위 | 우리(최고) | 격차 | 전체 격차 중 비중 | 1위 대비 도달률 |
|---|---:|---:|---:|---:|---:|
| Stage 1 재녹화 | 0.81342 | 0.4428 | **0.371** | **48%** | 54% |
| Stage 2 사고분석 | 0.31163 | 0.2325 | **0.079** | **10%** | **75%** |
| Stage 3 거동 | 0.5847 | 0.2683 | **0.316** | **41%** | 46% |

읽어야 할 것은 세 가지다.

1. **Stage 2는 우리가 가장 잘하고 있는 Stage다.** 1위가 0.312에 그친다는 것은 아무도 이 과업을 풀지 못했다는 뜻이고, 이는 `t_entry`·`evasion_space`·`entry_side`에 공개 정답이 없다는 사실과 정확히 일치한다. 전체 격차의 10%뿐인 이 Stage에 원안은 가장 많은 일정(9/05~9/11 주간 전체 + 직접 주석 프로젝트)을 배정하고 있었다. **이 배정은 잘못되었다.**
2. **Stage 3이 매우 학습 가능한 과업임이 증명되었다.** 1위 0.5847은 4클래스 + 3클래스 Macro-F1로서 높은 값이다. 공개 라벨 50점만 보고 “이 과업의 천장이 낮다”고 판단했던 것은 우리 특징(전체 프레임 광류 중앙값)의 천장이었지 과업의 천장이 아니었다. 제대로 된 ego-motion 추정이면 크게 오른다.
3. **Stage 1은 격차가 가장 크면서 유일하게 학습데이터 병목이 없는 Stage다.** 원본 주행 영상에 화면 재촬영을 시뮬레이션(픽셀 그리드/모아레, 미세 원근, 감마·대비 변화, 저비트레이트 재인코딩, 롤링셔터 밴딩)하거나 실제로 모니터를 재촬영하면 라벨이 무한히 생긴다. 베이스라인의 재녹화 예제가 바로 그 방식으로 만들어졌다.

### 개정된 노력 배분

| 순위 | Stage | 배분 | 근거 |
|---|---|---:|---|
| 1 | Stage 1 | 40% | 격차 최대(0.371) + 학습데이터를 자체 생성 가능 → 투입 대비 회수가 가장 확실 |
| 2 | Stage 3 | 40% | 격차 0.316이 실재하고 1위가 이미 0.585로 도달 가능함을 증명 |
| 3 | Stage 2 | 15% | 격차 0.079. 공개 정답이 있는 `collision_frame`만 개선하고 나머지 셋은 비용을 묶는다 |
| — | 실행시간·재현성 | 5% | 60분 제한은 실격 요인이지 점수 요인이 아니다 |

**중단 결정:** 원안의 “Stage 2 미표기 3항목 직접 주석 학습세트 구축”(9/05~9/11)은 **취소한다.** 최대 회수가 0.079이고 그중 3항목이 차지하는 몫은 그보다 작다. 같은 시간을 Stage 1 재녹화 데이터 생성에 쓴다.

**Stage 2의 대체 방침:** 공개 정답이 없는 `evasion_space`·`entry_side`는 약한 신호로 추정하지 말고, 채점식이 Macro-F1일 경우의 결정이론적 선택을 따른다. 이진 항목에서 한쪽으로 몰면 Macro-F1 상한이 약 0.33이지만 균형 있게 나누면 기대값이 약 0.5다. 파일 자체의 내용만으로 결정되는 결정적 규칙(예: 해당 파일 프레임 통계 해시)이면 “파일 단위 독립 예측” 규정에 저촉되지 않는다. **단, Stage 2 하위 항목의 채점식이 Macro-F1인지 정확도인지 아직 확인되지 않았다. 확인 전에는 적용하지 않는다.**

### 주의: 이 표의 한계

- 세 개의 1위 점수는 **서로 다른 팀의 것일 수 있다.** 동일 가중치 가정 시 “가상의 전 Stage 1위”는 0.570이며, 실제 종합 1위 팀의 점수는 그 이하다.
- **종합 가중치가 아직 공개되지 않았다.** 위 배분은 동일 가중치를 가정한다. 가중치가 공개되면 이 표를 가장 먼저 다시 계산한다.

### Stage 1에서 먼저 시도할 것 (순서대로)

1. 현재 점수(0.4428)는 전량 단일 클래스(약 0.333)를 겨우 넘는 수준이다. 지금 신호는 사실상 작동하지 않고 있다.
2. 2D FFT 기반 **주기적 패턴 검출**로 교체한다. 화면 재촬영은 고주파 에너지를 *늘리는* 것이 아니라 오히려 디테일을 뭉개면서 **주기적 구조**(픽셀 그리드, 모아레)를 더한다. 현재의 “고주파 에너지 평균”은 이 구분을 못 한다. 학습 없이도 개선 여지가 크다.
3. 그 다음 자체 생성 데이터로 소형 CNN(오프라인 가중치 동봉)을 학습하고 확률 보정까지 검증한다. 0.81 수준은 이 단계에서 나온다.
4. 2차 보고서를 위해 생성 절차와 원본 영상 출처를 생성 시점에 바로 장부에 남긴다.

## 오늘: 제출 3회는 이렇게 사용한다

| 순서 | ZIP | 의도 | 리더보드에서 볼 것 |
|---|---|---|---|
| 1 | `submit_a_conservative.zip` | 변화가 확실할 때만 이벤트·거동을 바꾸는 보수 가설 | 실행 성공 여부와 안정적인 기준점 |
| 2 | `submit_b_balanced.zip` | 충돌 전후 변화와 광류를 균형 있게 반영 | A 대비 전체 점수 변화 |
| 3 | `submit_c_responsive.zip` | 이른 진입·민감한 가감속/조향을 가정 | 점수 상승이 Stage 2/3 민감도 때문인지 확인 |

제출 순서와 점수, 코드 SHA/설정값, 실행 시간, 오류 유무를 한 줄씩 기록한다. 세 결과 중 최고 ZIP을 “기준 제출”로 고정하고, 다음 날에는 **한 번에 한 가설만** 바꾼다. 서로 다른 여러 변경을 섞으면 점수 차이의 원인을 알 수 없다.

## Stage별 모델 방향

### Stage 1 — 재촬영 판별

- 프레임 단위 공간 특징(모아레·스크린 도트·반사·검은 테두리·재인코딩 흔적)과 시간 특징(플리커·rolling shutter)을 함께 쓴다.
- 비디오 트랜스포머 1개와 이미지 기반 아티팩트 분류기 1개를 파일 내 여러 구간에서 추론하고 확률 평균한다.
- 검증은 반드시 **영상 단위**로 나눈다. 같은 원본의 인접 클립이 학습·검증에 섞이면 점수가 거짓으로 높아진다.
- Macro-F1 기준으로 임계값을 조정하며, 재촬영 확률 보정(calibration)을 별도로 검증한다.

### Stage 2 — 충돌·진입·회피·방향

- 시간 예측: 차량 검출·추적, optical flow, 프레임 차분, 오디오 충격(있다면)을 후보로 만들고 temporal transformer/TCN으로 프레임 점수를 낸다. 충돌 후보는 “실제 접촉”으로 재검증하고, 진입 후보는 피해차량을 충돌 프레임에서 과거로 역추적해 **피의차량 차선 최초 진입**을 찾는다.
- 장면 예측: 피해 차량과 차선의 상대 위치·TTC·충돌 직전 빈 공간을 입력으로 한 다중 헤드 분류기를 사용한다.
- 공개 라벨에서 `-1`인 세 항목은 정답처럼 학습하지 않는다. 합법적 공개 사고 영상 또는 직접 라벨링한 별도 학습 세트에서만 학습하고, 클래스 정의와 주석 기준을 문서화한다.
- 평가는 프레임 오차 대신 **초 단위 오차**로도 보며, ±0.3초 합격률을 직접 지표로 둔다. fps/가변 프레임레이트 변환이 틀리지 않는지 테스트한다. `entry_side`는 항상 영상 화면 좌우로 라벨링한다.

### Stage 3 — 가감속·조향

- 도로/차선 segmentation, ego-motion(광류·visual odometry), 객체 추적을 결합한 시계열 특징을 만든다.
- 비공개 영상은 10Hz이며 디코딩 프레임 수와 `sample_index` 수가 같다. 따라서 프레임 0부터 마지막 프레임까지 누락 없이 예측한다. 0.1초 주변의 양방향 문맥을 쓰되 출력 기준 시점의 미래 영상 사용이 허용되는지 규정을 확인한다. 허용되지 않으면 과거 문맥만 쓴다.
- 가속 4클래스와 조향 3클래스는 각각 class-balanced loss, 영상 단위 CV, 짧은 구간 평활화로 다룬다.
- `STOPPED`의 조향은 제출해야 하지만 점수 제외라는 점을 후처리에 반영한다.

## 실험의 최소 규칙

1. 한 실험은 데이터 버전, split seed, 코드 커밋, 모델, 임계값, 추론 시간, Stage별 지표를 남긴다.
2. 리더보드는 선택에만 쓰고, 모델 선택은 파일 단위 교차검증으로 한다. 공개/비공개 평가 데이터는 어떤 형태로도 학습에 넣지 않는다.
3. 새 외부 데이터는 먼저 라이선스, 다운로드 날짜, 원본 URL, 사용 목적, 전처리, 라벨 매핑을 장부에 적는다.
4. 최종 후보는 인터넷 차단·빈 캐시 환경에서 `pip install -r requirements.txt`부터 완주해야 한다.
5. 2차 진출을 가정해 모델 개발 보고서와 학습 데이터 구성 보고서를 실험과 동시에 갱신한다. 나중에 출처를 복원하려 하면 누락이 생긴다.
