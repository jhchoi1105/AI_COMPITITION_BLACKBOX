## 1. 즉시 시험: 정지 판정의 구조 교체

기존에는 각 영상의 `motion` 하위 42% 분위수에 1.03을 곱해 정지를 분류했다. 그 결과 지속적으로 주행하는 영상에서도 상당 구간을 STOPPED로 분류할 수 있다. 높은 정지 분위수가 과거 리더보드에서 유리했던 사실은 존중하되, 그것이 실제 정지를 잘 측정한다는 증거와는 구분한다.

E06은 같은 Farneback 광류와 같은 노면 운동 대리값을 사용한다. **정지 분류 규칙만 다음과 같이 교체**한다.

- 5프레임 중앙값으로 순간적인 움직임 잡음을 줄인다.
- 정지 진입: 정규화 운동량 0.003 이하가 3프레임 지속.
- 정지 해제: 0.005 이상이 2프레임 지속.
- 이미 정지해 시작하는 영상은 첫 5프레임 중앙값으로 초기 상태를 정한다.
- 정지 비율을 강제로 맞추지 않는다. 모든 프레임이 주행 또는 정지여도 가능하다.

0.003/0.005는 **현재 공개 10 Hz 광류 관측을 참고해 정한 실험값**이며 m/s가 아니다. 카메라 시야각·도로 깊이·노면·압축·주변 차량에 따라 달라진다. 카메라가 흔들리는 정지 영상과 아주 느린 주행을 혼동할 위험이 있다. 실제 차량 속도를 추정하는 학습 모델을 완성한 것은 아니다.

가감속 기울기·문턱·기존 가감속 평활화는 유지한다. 정지에서 해제된 행에는 기존 기울기 판정에 따른 ACCELERATING/DECELERATING/CONSTANT가 출력된다. 조향, Stage 1, Stage 2, 모델 가중치는 E05와 같다. E03에서 실패한 가감속 경계 변경이나 RAFT 재도입은 포함하지 않는다. 추가 광류나 새 대형 모델이 없어 계산 증가는 작은 1차원 후처리뿐이다.

| Stage 3 하락 | 현재 절대 운동량+지속성 규칙의 전이가 실패 | E05 유지. 같은 두 정차 영상에 문턱만 계속 맞추지 않는다. 시야각·주변 차량 영향을 덜 받는 자기운동 신호 또는 새 정차 자료가 준비된 후 재개한다 |
| Stage 3 동률 | 해당 평가에서 순이득 없음 | 발동·변경 규모와 폴백 로그를 점검하고 다른 정보원으로 이동한다 |
| Stage 1·2도 달라짐 / 실행 오류 | 통제 조건 또는 실행 문제 | 성능 해석보다 패키지·시간·환경 확인을 먼저 한다 |

한 번의 결과로 모든 정지 추정 방법을 기각하지 않는다. 반대로 한 번의 상승을 새 카메라 전체에 대한 일반화 증명으로 취급하지 않는다. 공식 집계 점수로 비공개 정답 클래스 비율이나 개별 라벨을 역산하지 않는다.

## 3. 더 큰 상한을 바꾸는 세 개발 경로

### A. Stage 3: 자기운동 특징 + 시계열 학습

지금의 평균 광류 크기는 주변 차량·도로 깊이·조향에 영향을 받는다. **차량의 운동 신호를 분리하는 것이 모델 크기보다 먼저**다.

1. 노면 좌우/먼 배경을 나누어 광류를 측정하고, 움직이는 전경과 카메라 회전의 영향을 줄인다.
2. 영상 특징에서 속력·가속도·회전율을 예측하는 작은 시계열 모델을 공개 실측 신호로 학습한다. 처음부터 큰 영상 모델 전체를 학습하기보다 캐시한 운동 특징과 짧은 시간 문맥으로 시작한다.
3. 정차/출발/제동/서행/지속 회전을 각각 검증한다. 단순 속력 상관만 보지 않고, 정지 F1·가감속 Macro-F1·전환 구간 오류를 함께 본다.
4. 같은 주행 세션의 프레임을 학습·검증에 섞지 않는다. 카메라/주행 세션 단위 분리와 별도의 최종 확인 자료가 필요하다.

현재 10개 영상만으로 충분한 학습·일반화 성능을 확보했다고 주장하지 않는다. 이 경로는 **추가 데이터 확보와 학습이 필요한 다음 작업**이며 이번 E06에 학습 모델이 들어간 것은 아니다.

### B. Stage 2: 충돌 시점과 회피 공간을 실제 장면 정보로 추정

진입 방향은 검출기를 도입해 이미 공식 이득을 얻었다. 반면 충돌은 화면 차분 정점, 회피 공간은 충돌 전후 변화량 비율에 크게 의존한다.

1. **충돌:** 여러 후보 시점에서 실제 상대 차량의 접근·접촉 위치·카메라 충격을 따로 측정하고 시간 모델로 결합한다. 단순 차분 문턱 재조정과 구분한다.
2. **회피 공간:** 충돌 이전 시점의 좌우 주행 가능 영역과 장애물 점유를 판정한다. 객체가 안 검출됐다는 이유만으로 주행 가능하다고 하지 않는다. 차선·보도·도로 경계를 보는 정보가 필요하다.
3. 별도 공개 사고 영상에 대회 정의와 일치하는 사건 주석을 추가한다. 기존 공개 5개 영상의 `-1`을 정답으로 쓰지 않는다. 사고 발생 시각, 위험 감지 시각, 실제 최초 접촉 시각을 구분한다.

현재 회피 공간을 학습할 정답이 없기 때문에, 검출기만 얹어 고득점 회피 공간 모델이 만들어졌다고 말할 수 없다. 새 상황 모델은 기존 방향 판정과 분리해 검증한다.

## 4. 여러 번 제출해도 낭비하지 않는 운영

- **단기 슬롯:** E06처럼 구조 하나가 최종 출력에 미치는 영향을 크게 구분하는 실험을 우선한다.
- **병행 개발:** 제출 결과를 기다리는 동안 새로운 정답 자료·자기운동 특징·시간 모델을 준비한다. 제출 횟수만 늘리는 것으로 정보 부족을 해결할 수는 없다.
- **승리 파일 보존:** 공식 최고 ZIP을 SHA와 함께 유지한다. 새 조합이 공식 검증되기 전에는 최고점으로 교체하지 않는다.
- **실패 시:** 실패한 구체적인 측정/판정 방식을 기록하고 다른 정보원을 시험한다. 같은 공개 자료의 문턱을 촘촘히 맞춰 반복 제출하지 않는다.
- **실행시간:** 무거운 시각 모델 추가 전에는 서버의 실제 Stage별 시간과 여유를 확인한다. E06은 새 대형 모델을 추가하지 않았다.

큰 도약의 가장 현실적인 경로는 **잘못 측정하던 과업을 직접 측정하고, 현재 자료와 다른 조건에서도 검증하는 것**이다. E06은 그 첫 번째 구조 실험이며, 더 높은 점수를 보장하는 완성 모델은 아니다.
