## 4. Stage 별 현재 구조

### Stage 1 — 재녹화 판별 (학습 없음)

16프레임을 **원본 해상도(최대 1920)** 로 표집해 5개 스칼라를 뽑고, 각 특징의 여유를
시그모이드(온도 0.45)로 바꿔 평균한 뒤 0.5 로 자른다.

| 특징 | 재는 것 | 재녹화 판정 |
|---|---|---:|
| `peak_prom` | FFT 스펙트럼에서 완만한 배경을 뺀 뒤 고리 영역 99.9분위 (모아레) | > 2.3912 |
| `hf_coarse` | 미세(σ=1.2)/거친(σ=4.0) 비율 | < 0.338 |
| `spec_slope` | log파워 vs log반경주파수 기울기 | < −3.0657 |
| `lap_kurt` | 라플라시안 첨도 | < 179.3935 |
| `sharp_spread` | 6×8 격자 선명도 비율의 표준편차/평균 | > 0.1726 |

**이긴 계열은 하나뿐**: "정보를 덜 버린다"(5승 0패). 온도는 0.10 → 0.25 → **0.45**
에서 정점(0.65 는 −0.0111, 극한도 패). 소프트 컷은 **0.50** 이 맞다(0.45 는 −0.0207).

### Stage 2 — 사고 주요시점 (프레임 차분 + Faster R-CNN)

노출 보정 차분(**480×270**, 포화점)의 봉우리 → 충돌, `충돌 − 22` → 진입,
충돌 전후 12프레임 변화량 비교 → 회피 공간, Faster R-CNN 궤적 → 진입 방향.

허용오차는 **±0.3초**이고 공개 클립이 50프레임·10fps 이므로 **±3프레임**이다.

### Stage 3 — 차량 거동 (학습 모델 + 광류)

| 경로 | 신호 |
|---|---|
| 가감속 기울기 | **학습 자기운동 모델의 속력(m/s)** — 350,007 파라미터, comma2k19 학습 |
| 정지 판정 | 배경 기준 보정 광류 + 절대 문턱 0.003/0.005 + 히스테리시스 |
| 조향 | 광류 수평성분 중앙값 + `std×1.1` + 히스테리시스 |
| 후처리 | 최빈값 필터 폭 3 |

## 5. 학습 자기운동 모델 (Stage 3 의 핵심)

comma2k19(comma.ai, **MIT License**) Chunk_1 + Chunk_3, **120 세그먼트 / 17 주행 /
2 차량**. `frame_velocities`·`frame_orientations` 가 프레임 단위 정답이다.
입력 96×160 프레임쌍 + 차분 3채널, 출력 (속력, 요레이트).

| 검증 방식 | 속력 상관 | 요레이트 상관 | 속력 MAE |

| 현행 광류 대리값 | 0.36 | 0.60 | — |
| 주행 단위 분리 (같은 카메라) | **0.961** | 0.845 | 1.94 m/s |
| **차량 단위 분리 (다른 카메라)** | **0.899** | 0.792 | **4.23 m/s** |

> **상관(상대 신호)은 잘 전이되는데 절대 보정은 2배 이상 무너진다.**

## 8. 방법론 — 지금까지 배운 규칙

1. **운영점은 리더보드로만 바꾼다.** 대리 자료로 고른 운영점은 **0승 4패**
   (E07 창 201 / E08 민감도 0.80 / E19 정지문턱 ×0.70 / E26 정지문턱 m/s).
2. **신호 변경은 5승 1패.** 다만 이득은 "학습 > 수작업"이 아니라
   **망가진 부품을 갈 때** 난다 (속도 0.36→0.961 승 / 요레이트 0.60→0.846 패).
3. **죽어 있는 기계를 찾아라.** 설정값은 있는데 코드가 그 값에서 아무 일도 안 하는
   자리가 반복해서 나왔다 — onset `alpha=1.0`, 최빈값 필터 `width=1`. 켜면 이긴다.
4. **낡은 기각은 구조가 바뀌면 무효다.** 낡은 **채택**을 새 구조에 옮기면 진다(E07).
   반대로 낡은 기각을 새 구조에서 다시 보는 것은 유효하다.
5. **비례 스케일링 변경은 양쪽 끝을 다 시험한다.**
6. **제출 전 필수 점검**: 검출기 프레임 수 · 단계별 시간 · 서버 시간 예측(가드 아래인지).
   출력 동일성만으로는 부족하다. fixture 는 **실제 연속 영상**으로.
7. **안전장치도 비용이 있다.** 가드는 한도에 붙인다.
8. **진단 제출은 공짜다.** 단계별 최고점이 누적되므로 하방이 없다. 채점식을 읽는
   제출이 개선 제출보다 값질 때가 많았다.
