# 블랙박스 영상 기반 지능형 고의사고 분석 모델 — DACON

블랙박스 영상으로 세 가지를 판별하는 대회 참가 기록이다.

| Stage | 과제 | 채점 | 가중치 |
|---|---|---|---:|
| 1 | 재녹화(화면을 다시 찍은 영상) 판별 | Macro-F1 | 0.2 |
| 2 | 사고 주요 시점: 충돌 프레임 · 진입 프레임 · 회피 공간 · 진입 방향 | ±0.3초 적중 / 분류 | 0.4 |
| 3 | 10Hz 차량 거동: 가감속 4범주 · 조향 3범주 | Macro-F1 | 0.4 |

제약: 추론 60분(L40S), 인터넷 금지(가중치 동봉), 평가 데이터 학습 금지, 파일 간 정보 사용 금지.

## 결과

| | Stage 1 | Stage 2 | Stage 3 | 가중합 |
|---|---:|---:|---:|---:|
| 최고 단일 제출 (E53) | 0.8955 | 0.3615 | 0.6663 | **0.5902** |
| 외부 데이터 도입 전 (E43) | 0.8955 | 0.3246 | 0.6342 | 0.5671 |

`final_submission/` 은 마지막으로 만든 제출본(E57)이다.
E53 에 아직 리더보드에 묻지 않았던 두 축을 더했다: Stage 2 판별기 충돌 편향 −2, Stage 3 속력 평활 25 + 민감도 0.38.

## 방법

### Stage 1 — 재녹화 판별 (학습 없음)
- 원본 해상도에서 24프레임을 표집하고, 프레임마다 질감 특징 5개를 계산한다.
  - FFT 봉우리 돌출도(모아레), 고주파/저주파 비, 스펙트럼 기울기, 라플라시안 첨도, 선명도 공간 편차
- 각 특징의 여유를 시그모이드(온도 0.45)로 바꿔 평균한 뒤 0.5 로 자른다.
- 프레임 수, 온도, 컷을 리더보드로 양쪽 끝까지 확인해서 이 설정에서 포화된 상태다.

### Stage 2 — 사고 주요 시점
- **충돌 프레임:** CCD 로 학습한 소형 CNN **3개 앙상블**로 고른다.
  - 프레임 t 주변 6장(160×90 회색)과 차분 5장을 넣으면, 클립 단위 softmax 로 "충돌 시작" 점수를 낸다.
  - 이것으로 바꾸기 전에는 "화면 변화량 최대 봉우리"였다. 교체로 **+0.019** 올랐다.
- **진입 프레임:** 충돌 − 28프레임. 리더보드 확인 결과 24 < **28** > 32 > 36 이었다.
- **회피 공간:** 충돌 전후 변화량 비교.
- **진입 방향:** COCO 사전학습 Faster R-CNN 으로 차량을 추적하고, 화면 좌우 변화량 중심을 함께 본다.

### Stage 3 — 차량 거동
- **속력:** comma2k19(MIT)로 학습한 자기운동 CNN(35만 파라미터)이 프레임쌍에서 속력을 낸다.
  - 이 속력의 기울기로 가감속을 판정한다. 문턱은 표준편차 × 배수다.
- **정지:** 배경 보정 광류에 절대 문턱과 히스테리시스를 건다.
- **조향:** 광류 수평 성분에 문턱(표준편차 × 0.9)과 히스테리시스를 건다.
- **후처리:** 최빈값 필터 41샘플. 1 → 3 → … → 41 로 늘리는 동안 일곱 번 연속 이겼다.

## 주요 발견과 교훈

1. **공개 Stage 1·2 예제는 CCD 원본 클립과 화소까지 같다.** 재녹화 예제도 같은 CCD 클립을 화면에서 다시 찍은 것이다.
   - DACON 에 문의해 CCD 학습 허용을 확인했다.
   - 평가 클립을 CCD 와 대조하는 방식은 누수 이용이라 쓰지 않았다.
2. **작은 모델은 CCD 에서 평가셋으로 옮겨졌지만, 큰 모델은 옮겨지지 않았다.**

   | 모델 | CCD 검증 | 리더보드 Stage 2 |
   |---|---:|---:|
   | 소형 CNN | +22%p | **+0.019** |
   | ImageNet ResNet18 섞기 | +2.5%p | **−0.057** |

3. **Q&A 를 읽으면 점수가 나온다.** "Macro-F1 은 정의된 전체 범주 기준"이라는 답변을 근거로 조향 문턱을 낮췄더니(드문 범주를 더 부르게) **+0.0105** 올랐다.
4. **운영점은 리더보드로만 고른다.** 대리 지표(공개 5개, comma2k19)로 고른 운영점은 대부분 졌다.
5. **실행 시간이 가장 큰 위험이었다.**
   - 시간 초과 신호: 54분 예산 방어가 발동하면 Stage 3 점수가 정확히 0.1656 이 된다.
   - 로컬 측정은 평가 비용을 과소평가했다(광류 해상도 4배 → 시간 초과).

전체 실험 흐름(E01~E57)과 판정은 [`docs/06_전체기록.md`](docs/06_전체기록.md) 에 있다.

## 저장소 구조

```
final_submission/        최종 제출본 (E57) — 이 폴더를 zip 으로 묶으면 제출 파일
  inference.py           predict_stage1 / predict_stage2 / predict_stage3
  collision_net*.pt      Stage 2 충돌 판별기 3개 (CCD 학습)
  ego_final.pt           Stage 3 자기운동 모델 (comma2k19 학습)
  vehicle_frcnn.pth      COCO 사전학습 Faster R-CNN 가중치 (Git LFS)
training/
  stage2_collision/      CCD 전처리(prep.py), 판별기 학습(train.py, train2.py), 휴리스틱 기준선(heur.py)
  stage3_egomotion/      comma2k19 자기운동 모델 학습
tools/
  audit.py               제출 전 규정·형식·예산 방어 점검
  build_e57.py           E53 → E57 패치 스크립트 (모든 제출본은 이런 결정론적 패치로 만들었다)
docs/                    전체 기록, Stage 2 구조 설명, DACON Q&A 정리
```

`vehicle_frcnn.pth`(175MB)는 Git LFS 로 올렸다. 클론할 때 `git lfs pull` 이 필요하다.
